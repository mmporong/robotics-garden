PID를 조정할 때는 보통 Kp, Ki, Kd부터 만져요. 하지만 숫자 세 개만 적어 두면 실험을 재현할 수 없어요. 같은 게인도 제어 주기, 출력 포화, 미분 필터, 신호 단위가 바뀌면 다른 제어기로 동작하기 때문이에요. 그래서 이번에는 조정법보다 먼저 비교 조건을 고정했어요.

이산 PID의 한 스텝은 다음처럼 쓸 수 있어요.

```text
e[k] = r[k] - y[k]
I[k] = I[k-1] + Ki · e[k] · dt
D[k] = -Kd · LPF((y[k] - y[k-1]) / dt)
u[k] = clamp(Kp · e[k] + I[k] + D[k], u_min, u_max)
```

적분에는 `dt`를 곱하고 미분에는 `dt`를 나눠요. 이 항이 빠지면 루프 속도가 게인의 일부가 됩니다. 오차 단위가 엔코더 펄스인지 rad/s인지, 출력이 PWM인지 전압인지도 같이 적어야 Kp·Ki·Kd의 단위가 정해져요.

## 현재 코드에서 확인한 구현 계약

PID 자동차 펌웨어는 20ms, 즉 50Hz마다 목표 엔코더 펄스와 현재 펄스의 차이를 계산해요. 기본 출력 최댓값은 PWM 200, 정지 마찰을 넘기기 위한 최솟값은 70이에요. 적분은 바퀴가 멈췄을 때만 누적하고 0~100으로 제한하며, 움직일 때는 0.9배로 줄여요. 출력 포화와 직접 연결한 back-calculation은 아니지만 조건부 적분과 clamp를 섞은 구조예요.

미분항은 `error - lastError`예요. 20ms가 식에 들어가지 않고 필터도 없어요. 따라서 지금의 Kd=0.1은 이 코드와 20ms 주기 안에서만 뜻이 있어요. 같은 오차가 초당 -2만큼 변할 때 dt 없는 D 출력은 10·20·40ms에서 각각 -0.002, -0.004, -0.008이었어요. `Δe/dt`로 계산하면 세 경우 모두 -0.2였어요.

이 차이는 버그라는 한마디로 끝낼 일이 아니에요. 현재 펌웨어는 펄스 위치 제어, 좌우 진행률 보정, 자이로 헤딩 보정을 한 출력에 합치고 있어요. 게인을 옮기기 전에 각 항의 단위와 역할을 분리해 기록해야 해요.

## 같은 plant에서 조정법만 바꿨어요

1차 지연과 dead time을 가진 수치 모델 `K=1, τ=1.4s, L=0.25s`를 만들고, 20ms 주기와 출력 한계 ±2를 고정했어요. Ziegler–Nichols 반응곡선법과 IMC/lambda(`λ=0.8s`)를 같은 조건에서 비교했어요. seed는 20260826으로 고정했고, 아래 값은 실기체 측정이 아니라 결정론적 simulation 결과예요.

| 조정법 | 상승 시간 | 정착 시간 | 오버슈트 | IAE | 포화 시간 |
|---|---:|---:|---:|---:|---:|
| Ziegler–Nichols | 0.76s | 14.00s | 8.23% | 0.996 | 0.92s |
| IMC/lambda | 1.46s | 2.72s | 0.37% | 0.927 | 0.00s |

Ziegler–Nichols가 처음에는 빨랐지만 정착과 포화에서 비용을 냈어요. delay를 0.25s 더했을 때 Ziegler–Nichols는 제한 시간 안에 정착하지 못했고, IMC/lambda는 정착했어요. Kp만 IMC 기준의 3배로 올린 run도 제한 시간 안에 정착하지 못했어요. 전체 19개 run 가운데 이 세 건은 평균에 섞지 않고 따로 실패로 기록했어요. 평균을 좋게 보이게 하려고 불안정하거나 미정착인 실험을 섞으면 조정법 비교가 무너져요.

## 포화는 출력만 자르는 문제가 아니에요

목표를 2.0에서 0.5로 내리는 동일 실험에서 anti-windup을 끄자 적분 상태의 절댓값이 88.889까지 쌓였고 제한 시간 안에 새 목표로 회복하지 못했어요. 조건부 적분과 back-calculation은 둘 다 0.60s에 오차 10% 안으로 돌아왔어요. 최대 적분 상태는 각각 0.609와 5.056이었어요.

두 방법의 숫자가 같다는 뜻은 아니에요. 조건부 적분은 포화를 더 밀어붙이는 방향에서 누적을 멈추고, back-calculation은 포화 전후 출력의 차이로 적분 상태를 되돌려요. 수동 출력에서 자동 PID로 전환할 때도 적분 상태를 현재 출력에서 P항과 D항을 뺀 값으로 초기화했어요. 이 실험의 첫 출력 점프는 0.00963이었어요.

## 자동 조정도 이 계약을 대신 정해 주지는 않아요

Ziegler–Nichols와 Cohen–Coon은 plant 반응에서 조정값을 만들었고, IMC는 응답 속도와 강인성의 절충을 lambda로 드러냈어요. relay autotuning은 폐루프에서 한계 진동 정보를 얻어요. 최근 연구는 Bayesian optimization이나 강화학습으로 목적함수와 제약을 함께 다뤄요.

방법은 발전했지만 질문은 남아요. 어떤 sample time과 출력 한계에서 시험했는지, 미분 필터와 anti-windup을 baseline에도 똑같이 줬는지, 실패 run을 어떻게 셌는지 확인해야 해요. 안전 제약을 둔 자동 조정도 초기 범위와 비용함수 밖의 위험을 없애 주지는 못해요. simulation에서 학습한 정책은 실제 마찰, backlash, 배터리 전압, 통신 지연을 다시 검증해야 하고요.

그래서 다음 실기 비교표의 첫 네 줄은 게인이 아니에요.

| 먼저 고정할 것 | 기록할 값 |
|---|---|
| sample time | 제어 틱의 목표·실측 분포, jitter |
| saturation | 출력 상·하한, dead zone, slew rate |
| derivative | measurement 미분 여부, 필터 시정수 |
| unit | setpoint·measurement·output의 물리 단위 |
| 그다음 | Kp·Ki·Kd, anti-windup, 조정법, seed |

이 계약을 고정한 뒤 rise time만 보지 않고 settling time, overshoot, 정상상태 오차, IAE·ISE·ITAE, control effort, 포화 시간을 함께 봐야 해요. 빠른 한 번보다 조건이 바뀌어도 실패하지 않는 제어기를 고르는 기준이 됩니다.
